# AVESTORA — وب‌سایت آژانس دیجیتال

یک وب‌سایت کامل فارسی (راست‌به‌چپ) در قالب **یک فایل مستقل**: تمام HTML، CSS و JavaScript داخل `index.html` قرار دارد. بدون React، بدون Next.js، بدون Tailwind، بدون مرحله بیلد و بدون نصب پکیج.

---

## ۱) اجرا

**ساده‌ترین راه:** فایل `index.html` را در یک مرورگر مدرن باز کنید (دوبار کلیک). همه بخش‌ها، منو، اسکرول هیرو، فیلترها و فرم بدون هیچ ابزار اضافه‌ای کار می‌کنند.

**اجرای محلی با سرور (پیشنهادی):**

```bash
python3 -m http.server 8000      # یا هر سرور استاتیک دیگر
```

**اجرا در محیط سندباکس Base44:**

```bash
docker compose -f docker-compose.base44.yml up -d --build   # نمایش روی پورت ۳۰۰۰
```

---

## ۲) تنظیمات — همه در یک نقطه

بالای بخش `<script>` در `index.html` یک شیء به نام `CONFIG` قرار دارد:

```js
HERO_VIDEO_URL: '',        // آدرس ویدئو (mp4/webm). خالی = نمای ثابت سینمایی CSS
HERO_VIDEO_SCRUB: true,    // با اسکرول، ویدئو جلو/عقب می‌رود (false = پخش آرام پشت‌زمینه)
FORM_ENDPOINT: '',         // آدرس دریافت فرم. خالی = ارسال آنلاین فعال نیست
FORM_TIMEOUT_MS: 12000,    // مهلت انتظار برای پاسخ سرور
CONTACT: { EMAIL:'', PHONE:'', WHATSAPP:'', INSTAGRAM:'', LINKEDIN:'' }
```

هر مقدار خالی بماند، همان گزینه به‌طور کامل از صفحه حذف می‌شود (هیچ آیکون یا لینک بی‌مقصودی نمایش داده نمی‌شود). هیچ شماره، ایمیل یا صفحه اجتماعی جعلی در فایل وجود ندارد و باید مقادیر واقعی خودتان را وارد کنید.

- **ویدئوی هیرو:** یک فایل رقص نور/شهر شبانه مرتبط با فضای دیجیتال یا برند خودتان را در `HERO_VIDEO_URL` بگذارید. اگر ویدئو بارگذاری نشود، سایت به‌صورت خودکار به نمای ثابت برمی‌گردد و خطایی رخ نمی‌دهد.
- **واتساپ:** می‌توانید شماره (`+98912...`) یا لینک کامل `https://wa.me/...` را وارد کنید.
- **اینستاگرام و لینکدین:** آدرس کامل یا نام کاربری را وارد کنید؛ نام کاربری به‌طور خودکار به آدرس پروفایل تبدیل می‌شود.

---

## ۳) اتصال فرم به سرور واقعی

فرم اعتبارسنجی کامل دارد، اما **تا زمانی که `FORM_ENDPOINT` خالی است هیچ پیامی ارسال نمی‌شود** و سایت این موضوع را صریح به کاربر اعلام می‌کند (پیام موفقیت جعلی نمایش داده نمی‌شود).

برای فعال‌سازی:

1. یک endpoint بسازید که درخواست `POST` با بدنه JSON را بپذیرد.
2. آدرس آن را در `FORM_ENDPOINT` قرار دهید.

ساختار بدنه ارسال‌شده:

```json
{
  "name": "...", "business": "...", "phone": "...", "email": "...",
  "service": "website", "budget": "unknown", "details": "...",
  "consent": true, "plan": "رشد و بازاریابی مستمر",
  "page": "...", "submitted_at": "2026-01-01T00:00:00.000Z"
}
```

پاسخ‌های ۲xx موفق، خطای سرور، پایان مهلت انتظار و قطع اتصال هرکدام پیام فارسی جداگانه دارند.

> نکته امنیتی: این یک صفحه استاتیک است؛ هر مقداری داخل آن عملاً برای همه قابل مشاهده است. کلید محرمانه، توکن دسترسی یا اطلاعات محرمانه در فایل قرار ندهید. اگر به کلید نیاز دارید، فرم را از طریق یک سرویس واسط (مثلاً یک تابع سرور یا فرم‌سرویس) به سرویس نهایی وصل کنید.

## ۴) انتشار روی دامنه

۱. فایل را روی هاست خود بگذارید (هر هاست استاتیک یا CDN). با یک فایل، بدون بیلد.
۲. در `<head>`، مقدار `rel="canonical"` و `og:url` را از `https://example.com/` به دامنه واقعی تغییر دهید و در صورت نیاز تصویر اشتراک‌گذاری (۱۲۰۰×۶۳۰) و فاوآیکون اختصاصی را اضافه کنید.
۳. راه‌های ارتباطی و `FORM_ENDPOINT` را با مقادیر واقعی کامل کنید.
۴. برای سئو: صفحه در `lang="fa"` و `dir="rtl"` است و عنوان، توضیحات و ساختار هدینگ‌ها تنظیم شده‌اند. مراحل بعدی به دامنه، استراتژی محتوا، ابزار تحلیل ترافیک و بک‌اند دریافت فرم وابسته است و در همین فایل قابل انجام نیست.
۵. اگر روی سرویس‌های CDN میزبانی می‌کنید، بررسی کنید که فونت‌ها (Vazirmatn / Inter Tight از Google Fonts) مجاز باشند؛ در غیر این صورت سایت به‌صورت خودکار از فونت‌های جایگزین استفاده می‌کند.

---

## ۵) دسترس‌پذیری و حرکت

- پشتیبانی از `prefers-reduced-motion`: با فعال‌بودن این تنظیم، اسکرول-اسکراب هیرو، پارالاکس و انیمیشن‌ها غیرفعال می‌شوند و نمای ثابت نمایش داده می‌شود.
- سایت با کیبورد کامل قابل استفاده است (ناوبری، تب‌های مدل رشد با کلیدهای جهت‌دار، آکاردئون سؤالات، دیالوگ‌ها با کلید Escape).
- در صورت غیرفعال بودن JavaScript، تمام متن‌ها و مسیرهای اصلی قابل خواندن است و کنترل‌های وابسته به JS پنهان می‌شوند.
